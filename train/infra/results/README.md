# results/

Small server handoff results are uploaded here by the remote machine.

Allowed:

- `status.txt`
- `summary.json`
- `environment.txt`
- `commands.log`
- small YAML manifests generated by smoke scripts
- small one-item toy JSONL files produced by the smoke, if needed for debugging
- tiny smoke evidence such as `loss.csv`, `sample_generation.txt`, and adapter
  manifests that do not contain model weights

Forbidden:

- model checkpoints;
- LoRA adapters;
- merged model weights;
- full generated training datasets;
- raw simulator outputs or waveform dumps;
- secrets, tokens, `.env` files;
- wandb local directories.
- any files from `/tmp/vaevas-training-paper-design-tiny-sft/<run_id>/`.

Each result directory should be named by run ID:

```text
train/infra/results/server-handoff-YYYYMMDDTHHMMSSZ/
```

Commit message template:

```text
Upload server handoff smoke result <run_id>
```
